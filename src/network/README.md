# [모듈3] 매개중심성 네트워크 분석

> **"이 도로가 막히면 정체가 대전 전역으로 얼마나 퍼지는가"**를 정량화하여
> XGBoost 임계도달 분류 모델의 입력 피처로 공급합니다.

---

## 실행 방법

```bash
pip install networkx geopandas pandas openpyxl shapely folium
python run.py         # BC 계산 + 기상 + 우선순위 (약 8분)
python visualize.py   # 지도 4종 생성
```

## 분석 방법론

### 1. 매개중심성 3시나리오

| 시나리오 | 가중치 | 의미 |
|---|---|---|
| `bc_free_flow` | 제한속도(MAX_SPD) | 공사 전 기준선 |
| `bc_under_construction` | MAX_SPD × HCM 패널티 | 공사 이론적 영향 |
| **`bc_its_realtime`** | **ITS 실측 속도** | ★ 현실 반영 핵심 피처 |

- DiGraph (18,236 노드, 25,397 엣지)
- **앙상블 4회 평균** (seed 42/0/123/777) → 실질 3,644 소스 노드
- ITS 실측 14,221개 링크 적용 (주요 간선 전수), 미관측 소로는 패널티 모델 폴백

### 2. 공사 패널티 (HCM 2010 + GIS 좌표)

통제현황 텍스트에서 차로 수 직접 파싱 → 잔여 비율 → 속도 패널티

| 잔여 차로 비율 | 패널티 | 예시 |
|:---:|:---:|---|
| > 75% | 0.75 | 도안대로 7공구 (잔여83%) |
| 50~75% | 0.55 | 한밭대로 3공구 (잔여73%) |
| 35~50% | 0.40 | 중앙로 13공구 (잔여50%) |
| < 35% | 0.25 | 계족로 2공구 (잔여25%) |

- 공사 자연어 주소 → 표준노드 교차로명 매칭 (19/19 성공)
- 시점~종점 버퍼 내 링크만 패널티 적용

### 3. ITS 640일 공구별 착공일 기준 전/후 비교

각 공구의 실제 착공일을 기준으로 전/후 속도를 분리 산출 (7일 간격 샘플링, 92일분 처리)

| 공구 | 도로 | 착공일 | 전 → 후 | 변화 |
|---|---|---|---|---|
| 14공구 | 동대전로·한밭대로 | 2026-04-15 | 33.0 → 30.1 | **-8.8%** |
| 12공구 | 충무로 | 2026-01-12 | 24.0 → 22.0 | **-8.6%** |
| 3공구 | 한밭대로 | 2026-06-01 | 34.1 → 31.7 | **-7.1%** |
| 4공구 | 한밭대로·대덕대로 | 2026-03-16 | 31.5 → 29.8 | -5.5% |
| 1공구 | 신탄진로 | 2026-01-15 | 36.4 → 34.5 | -5.2% |

### 4. 기상 위험도 (ASOS 실측 651일)

대전 133번 관측소 실측 기반:
- 강수 ≥30mm/h → 0.80, 기온 <0°C → +0.30, 적설 ≥3cm → +0.40

### 5. 구간 우선순위 스코어 (0~100)

BC(40%) + 차로감소(30%) + 도로위계(20%) + 기상(10%)  
segment 체계: 팀 공용 `segment_link_mapping.csv` 기준 45개 구간

## 핵심 결과

### BC 상위 5개 도로 (ITS 실측)

| 순위 | 도로명 | BC | 의미 |
|:---:|---|:---:|---|
| 1 | 한밭대로 | 0.068 | 도심 중앙축, 차단 시 도시 이분 |
| 2 | 대전천북로 | 0.066 | 한밭대로 병행 우회로 |
| 3 | 천변도시고속도로 | 0.066 | 갑천변 남북축, 우회 최대 흡수 |

### 원촌육교 사태 검증

원촌육교 500m 반경 = BC **상위 0.1%** (전체 21위)  
1km 내 정체 전이 경로 = 천변/갑천도시고속도로 → 실제 2026.4 사태와 정확 일치

## XGBoost 피처 연결

| 컬럼 | 역할 |
|---|---|
| `bc_its_realtime` | ★ 실측 구조적 파급력 (percentile rank 변환 권장) |
| `bc_its_vs_free` | 현재 vs 정상 파급력 격차 |
| `bc_change` | 공사 전후 이론적 위험 증가분 |
| `lane_remain_ratio` | 잔여 차로 비율 (0~1) |
| `segment_id` | 팀 공용 구간 키 (segment_link_mapping 체계) |
