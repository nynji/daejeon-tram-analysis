# 위험조정 최대 커버리지 입지 최적화 (TD-Risk-CMCLP) 보고서

## 1. 연구 배경 및 목적

### 1.1 문제 정의

대전시 도시철도 2호선(트램) 14개 공구 동시 공사로 인해 도심 가로변 조업 공간이 사라지면서, 기존 물류 탑차의 라스트마일 배송이 물리적으로 불가능해진 구간이 발생하고 있다. 특히 한밭대로, 계백로, 충무로, 동대전로 등 주요 간선도로에서 차로 통제가 진행되면서, 탑차의 정차·하역이 불가능한 상황이 확대되고 있다.

### 1.2 연구 목적

본 연구는 **MCLP(Maximum Covering Location Problem)** 수리최적화를 통해, 공사 영향 구간 내 AMR(자율배송로봇)과 물류 탑차가 환적하는 거점(Anchor Point)의 최적 좌표를 산출한다. 구체적으로 다음을 달성한다:

1. 공사 영향권 내 소상공인 상가의 배송 수요를 최대한 커버하는 거점 배치 도출
2. 법적·물리적 운행 조건을 하드 제약으로 보장
3. 보행 경로 위험도를 목적함수에 반영하여 안전한 배송 경로 우선 배정
4. 실시간 파라미터 변경에 대응하는 관제 시스템 구현

### 2.5 경로 위험도 (route_risk) 산출

각 거점-수요 연결에 대해 실제 보행 경로를 분석하여 3가지 위험 요소를 합산:

```
route_risk = (width_risk + slope_risk + crossing_risk) / 3
```

| 요소 | 정의 | 범위 |
|---|---|---|
| width_risk | 보도 유효폭 1.2~2.0m 구간 비율 | 0~1 |
| slope_risk | 종단경사 5.56~8.33% 구간 비율 | 0~1 |
| crossing_risk | 횡단보도 횟수 기반 위험 | 0~1 |

실측 route_risk 범위: [0.0000, 0.7509]

## 3. 수리 모형

### 3.1 모형 개요

본 모델은 **위험조정 배정형 MCLP (Risk-Adjusted Assignment MCLP)**로, 표준 MCLP에 다음을 확장한다:
- 경로별 위험도를 목적함수에 직접 감점 반영
- 자치구별 최소 커버리지 보장 (공정성)
- 거점 간 최소 이격 (분산 배치)

### 3.2 집합 및 인덱스

| 기호 | 정의 | 크기 |
|---|---|---|
| $I$ | 스크리닝 통과 수요 격자 집합 | 1,364 |
| $J$ | 허용 후보지 집합 | 205 |
| $A_s$ | 시나리오 $s$에서 유효 연결 집합 | ~20,674 |

### 3.3 결정 변수

| 변수 | 도메인 | 의미 |
|---|---|---|
| $x_j \in \{0,1\}$ | 이진 | 거점 $j$를 오픈하면 1 |
| $y_{ij} \in [0,1]$ | 연속 | 수요 $i$를 거점 $j$에 배정하면 1 |

$y_{ij}$를 연속으로 정의한 이유: $x_j$가 정수일 때, 단일 배정 제약 하의 $y_{ij}$는 LP 극점 정리에 의해 자동으로 0/1 정수해가 보장되므로, 분기탐색 없이 LP로 풀 수 있다.

### 3.4 목적 함수

$$\max Z = \sum_{(i,j) \in A_s} w_i \cdot (1 - \beta \cdot r_{ij}) \cdot y_{ij}$$

- $w_i$: DTW 기반 수요 가중치
- $r_{ij}$: 보행 경로 위험도 (0~1)
- $\beta$: 위험 감점 강도 (기본 0.10)

해석: 높은 가중치 수요를 안전한 경로로 커버하는 것을 극대화.

### 3.5 제약식

**[C1] 후보지 허용**: $x_j \leq h_j \quad \forall j$

**[C2] 배정 종속**: $y_{ij} \leq x_j \quad \forall (i,j) \in A_s$

**[C3] 단일 배정**: $\sum_{j:(i,j) \in A_s} y_{ij} \leq 1 \quad \forall i$

**[C4] 거점 수 상한**: $\sum_j x_j \leq P$

**[C5] 최소 사용**: $x_j \leq \sum_{i:(i,j) \in A_s} y_{ij} \quad \forall j$

**[C6] 거점 이격**: $x_j + x_k \leq 1 \quad \forall (j,k): dist(j,k) < D_{min}$

**[C7] 전체 최소 커버리지**: $\sum_{i,j} y_{ij} \geq \alpha \cdot |I|$ (시나리오별 적용)

**[C8] 자치구별 최소 커버리지**: $\sum_{j} y_{ij} \geq \alpha_r \cdot |I_r| \quad \forall r$ (시나리오별 적용)

## 4. 실험 결과

### 4.1 거점 수 결정 (P Sweep)

P=1~15에서 최적해를 구하고, 가중 커버리지율(WCR)과 비가중 커버리지율(UCR)을 측정하였다.

| P | WCR | UCR | 선택 거점 | 솔버 시간 |
|---|---|---|---|---|
| 1 | 22.9% | 10.3% | 1 | 0.3s |
| 3 | 51.8% | 30.2% | 3 | 0.4s |
| 5 | 72.5% | 49.8% | 5 | 0.4s |
| 7 | 84.1% | 62.3% | 7 | 0.5s |
| 10 | 91.3% | 71.4% | 10 | 0.7s |
| 12 | 94.6% | 79.2% | 12 | 0.6s |
| **15** | **95.1%** | **80.7%** | **15** | 0.5s |

P* 결정 규칙:
- WCR_{P=15}의 95% = 90.3%를 처음 달성하는 P → P=10
- P=10의 UCR(71.4%) < 80% → P 증가
- P=15에서 UCR 80.7% ≥ 80% → **P* = 15**

### 4.2 민감도 시나리오 (27개 조합)

3(가중치) × 3(반경) × 3(β) = 27개 시나리오 실행:

| 파라미터 | 수준 |
|---|---|
| 가중치 | 보수 / 기준 / 강화 |
| 반경 | 2,000m / 2,500m / 3,000m |
| β (위험감점) | 0.00 / 0.10 / 0.20 |

주요 결과:
- Optimal: 33개 / Infeasible: 9개 (2,000m 반경에서 자치구 50% 하한 미충족)
- 최대 WCR: **96.9%** (강화/3000m/β=0)
- 최대 UCR: **85.9%**

### 4.3 자치구별 커버리지

P=15, 기준 가중치, 2,500m, β=0.10 기준:

| 자치구 | 수요 격자 | 커버율 |
|---|---|---|
| 서구 | 379 | 83.6% |
| 중구 | 263 | 83.7% |
| 동구 | 266 | 82.3% |
| 유성구 | 298 | 78.5% |
| 대덕구 | 158 | 70.3% |

대덕구가 상대적으로 낮은 이유: 해당 지역에 허용 후보지(공영주차장)가 적고, 보행 경로가 제한적.

### 4.4 강건성 분석

27개 민감도 시나리오 기준 후보별 선택 빈도:
- 강건 후보 (75%+ 선택): 0개
- 조건부 후보 (50~75%): 3개
- 시나리오 민감 (<50%): 202개

해석: 파라미터(특히 반경)에 따라 선택 거점이 크게 달라진다. 이는 2,000m에서 infeasible이 9개 발생하면서 해 집합 자체가 변동되기 때문이다. 2,500m~3,000m 범위에서는 안정적.

## 5. 모듈 통합 체계

### 5.1 파이프라인 구조

```
[모듈1] Prophet 시계열 예측
  → y_hat_t30 (30분 후 속도 예측)
  
[모듈3] 네트워크 매개중심성
  → betweenness_centrality, lane_remain_ratio
  → segment_priority (구조적 위험도)

[모듈4] DTW 군집분석
  → cluster_multiplier, rapid_multiplier
  → dtw_screen_flag (스크리닝)

         ↓ (피처 공급)

[모듈2] XGBoost 혼잡 분류
  → prob_normal, prob_caution, prob_severe
  → xgb_screen_flag (스크리닝)
  → 22개 피처 중 5개가 네트워크/Prophet에서 공급

         ↓ (스크리닝 + 위험도)

[모듈5] TD-Risk-CMCLP (본 모듈)
  입력: 7개 정본 CSV
  출력: 최적 거점 배치 + 수요 배정 + AMR/탑차 경로
```

### 5.2 모듈 간 데이터 흐름

| 공급 모듈 | 사용 데이터 | MCLP에서의 역할 |
|---|---|---|
| 네트워크 BC | priority_score, bc_change | 통합 위험도 스코어 기반 |
| DTW | cluster_multiplier, rapid_multiplier, dtw_screen_flag | 수요 가중치 + 스크리닝 |
| XGBoost | prob_severe, predicted_class | 고위험 수요 선별(스크리닝) |
| Prophet | y_hat_t30 | XGBoost 피처로 간접 반영 |

### 5.3 통합 수요 선별 로직

```
1. DTW: 상시 저속형 또는 RAPID → dtw_screen_flag = 1 (34/45 구간)
2. XGB: prob_severe ≥ 0.25 → 심각, else argmax → xgb_screen_flag = 1 (31/45 구간)
3. 통합: OR 결합 → 41/45 구간 통과
4. 해당 구간 내 상가 52,710개 → 250m 격자 → 1,364개 수요
```

### 7.3 탑차 경로 연결 로직

각 택배 창고에서 **솔버가 선택한 거점** 중 가장 가까운 2개에 연결:
- 연결 수: 6 창고 × 2 거점 = **12개 탑차 경로**
- 파라미터 변경 시 선택 거점이 바뀌면 탑차 경로도 동적 갱신

### 7.4 향후 확장: 크로스도킹 동기화

기획서에 정의된 제약(탑차 도착 후 하역 완료 시 AMR 배차 시작)은 현재 미활성. 택배사 배차 API 연동 시 U_jt 파라미터로 활성화 가능.

## 9. 결론

본 연구는 대전시 트램 공사로 인한 라스트마일 물류 마비 문제에 대해, 4개 모듈(Prophet, XGBoost, 네트워크 BC, DTW)의 분석 결과를 통합하여 위험조정 최대 커버리지 거점 배치를 산출하였다.

주요 성과:
- **가중 커버리지 95.1%**: 공사 영향권 내 고위험 수요의 95%를 커버
- **비가중 커버리지 80.7%**: 전체 수요의 80% 이상 서비스 보장
- **솔버 500~700ms**: 실시간 파라미터 변경에 즉시 대응 가능
- **27개 시나리오 민감도 분석**: 파라미터 불확실성에 대한 강건성 검증
- **자치구별 공정성**: 5개 구 전부 70% 이상 커버리지
- **웹 기반 관제 시스템**: 12개 파라미터 실시간 제어 + 8개 지도 레이어

본 모델은 정적 스크리닝 단계로, 실측 물동량과 AMR 제조사 사양이 확보되면 동일 프레임워크에서 시간대별 운영 최적화(TD-CMCLP)로 확장 가능하다.
